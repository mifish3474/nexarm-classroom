Connect the robot, then Run your program.

Run checks the destinations, returns to Home, then starts your blocks. If all joints are already close to Home, no return move is needed. Stop cancels both the return and the program. Connecting and loading files do not move the arm.

Save downloads a JSON file with the connected program and its used positions. Load restores blocks for review; it never runs the robot.

XYZ/P/R/C targets are checked against all six joint ranges before any program movement. Unsupported calculations or out-of-range targets stop the program. Movement follows joint-space paths; joint limits do not guarantee clearance between parts of the arm or obstacles.

    Release, record, and restore

    Release and Restore are above Run program. Support the arm's weight while released, move it gently, and never force a resisting joint. Record a stationary pose, restore holding, and check that it holds before removing support.
