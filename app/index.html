Help & tools

Drag blocks into a sequence, or use Add block. Select a block's values to edit them. Use Repeat to run the blocks inside it more than once. My Blocks define named sequences: put a call in Run, a key event, or another My Block. Definitions do not run on their own. Use shared variables; parameters and return values are not available yet. Name your project above the code before saving.

Run checks startup and known key targets, returns Home once, then starts your blocks. Key events share variables and check each new target before moving. Space or Stop cancels the return, program and key events, sends a fast hold, waits for fresh, steady post-hold readings, then requests release of all six servos. Support the arm; use Restore & Return Home to recover, or Hold current position to keep this pose. Clear the full sweep before returning Home. Nothing resumes automatically. Space works only when this page receives the key. Keep the whole sweep clear and the physical power cutoff accessible.

The tower pulses green during programs (including Home and waits), amber while listening for keys, and red after Stop or a fault. It reports software activity; it does not prove the arm has stopped.

Saved positions advance on frame time; exact arrival is not verified. Add Wait for a pause. Maximum: 20 repeats, 100 expanded steps, 60 seconds.

Development testing: current operating ranges, speed up to 600, acceleration 10. Protected student policy is pending. Software Stop is not a certified emergency stop.

Program steps and keyboard editing

Edit numeric values here. Plug Math and Variables blocks into targets, durations and repeat counts. Conditions use program values; all calculations finish before movement. All stacks and My Blocks share variables within a Run session. Run starts with fresh variables, checks Home once, and runs startup blocks before listening. Each key press calculates from the current shared values and continues from the current pose. Check program is an offline preview; Stop ends the session.
